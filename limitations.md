# Limitations

- The full working dataset is synthetic.
- Some patterns were deliberately embedded for educational demonstration.
- Findings are illustrative rather than real-world operational conclusions.
- Association does not establish causation.
- The dataset lacks enough contextual process variables to establish actual root causes.
- July contains only nine records and should be treated cautiously in trend interpretation.
- The project includes an **OEE-like** metric for illustration; it is not presented as formal OEE.
