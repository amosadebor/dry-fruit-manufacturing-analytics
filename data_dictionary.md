# Data Dictionary

The project dataset covers the following analytical dimensions:

- **Production:** target output, actual output and related production measures
- **Downtime:** planned changeover and downtime duration
- **Quality:** rejects and rework
- **HSE:** PPE compliance, housekeeping, GMP, safety observations and incident type
- **Corrective action:** action status
- **Maintenance:** maintenance type and maintenance duration
- **Operations:** product, machine, shift and production date
- **Resource use:** fuel usage

The calculated KPI layer includes production attainment, reject rate, downtime rate, net good output and an OEE-like illustrative metric. The project intentionally does not label the latter as formal OEE.
